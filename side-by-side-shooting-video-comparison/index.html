Split Sync 布局 · 同一次 Run

并排对比两个同步射击视频

Side by Side 不是独立编辑模式，而是 Shooting Cut Pro 的 Split Sync 四种布局之一：导入同一次 Run 的恰好两个同步视频，用计时器蜂鸣或音频事件对齐并人工复核，再把两个画面并排放进同一成片。

Side by Side 属于 Split Sync

Split Sync 提供 Full Screen、Dual View: Center HUD、Dual View: Top HUD 与 Side by Side 四种布局。Side by Side 只是其中一种成片组合方式，仍然遵守 Split Sync 的所有输入、同步、Pro 与输出边界。

它不能单独接收任意数量的素材，也不会把两个无关视频自动变成技术分析报告。两个输入必须记录同一次 Run，才能在同一时间点比较动作与画面信息。

选择同一次 Stage 的两个同时拍摄视角

常见组合包括射手 POV 与场外 Follow，或同一 Stage 的两个固定位置。两个机位都应尽量保留计时器蜂鸣声，并覆盖可用于交叉确认的起跑、进入射击位置、射击和换位动作。

素材关系决定模式。Stage 1 与 Stage 2 是前后顺序素材，应使用 Merge；同一次 Stage 的两个同时拍摄视角才适合 Split Sync。

先同步，再选择并排布局

  1. 导入恰好两个同步视频。确认两段素材来自同一次 Run，并保留相同的开始蜂鸣声。
  2. 运行计时器与音频对齐。Shooting Cut 在两条音轨中寻找可比对的蜂鸣声，生成时间线偏移建议。
  3. 人工复核同步点。试听蜂鸣、首发与后续事件，并用画面中的共同动作确认两个视角没有提前或滞后。
  4. 选择 Side by Side。预览左右画面中主体的可见面积、字幕安全区与关键动作。
  5. 完整播放后导出。确认同步从开始到结束都成立，再生成由该布局控制的成片。

完整同步设置、四种布局与短边 1080 像素输出边界，请参阅Split Sync 完整指南。

并排画面适合做同一时刻的视角对照

Side by Side 的合理对比方式
视角组合能看清什么仍需人工判断
POV + Follow第一人称方向与场外整体移动同时发生的过程哪个画面更能表达当前动作
两个固定视角同一 Stage 在不同覆盖区域中的路线与遮挡是否存在拍摄死角或不同步
近景 + 广角操作细节与整体场景的时间关系并排后主体是否仍足够清晰

这些例子是观看与复核方式，不代表应用会对动作质量、器材使用或成绩原因作出自动技术结论。

需要自动切换时应选择 Stage Mix

Side by Side 会持续呈现并排布局。若同一次 Stage 有 2–3 个 POV、Follow 或 Static 输入，并希望根据移动状态先生成机位切换建议，再手动覆盖切点，应使用 Stage Mix。
