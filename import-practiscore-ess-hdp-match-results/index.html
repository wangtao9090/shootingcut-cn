导入 PractiScore、ESS、HDP 与 IDPA 比赛成绩

Shooting Cut 当前可从 PractiScore、ESS、HDP 与 IDPA 来源导入比赛、射手、Stage 和成绩信息，并把选定记录关联到你的本地比赛视频；导入使用网络，且前提是来源仍然提供相应比赛与成绩。

来源可用于什么逐发时间边界

IDPA导入受支持的比赛与成绩信息不提供 PractiScore 风格的官方逐发时间锚点

“成绩导入”描述的是这些明确受支持的来源家族，不代表可以接受任意成绩系统或任意文件格式。

从来源记录到本地视频关联的五个步骤

  1. 选择成绩来源。根据比赛实际使用的系统选择 PractiScore、ESS、HDP 或 IDPA。
  2. 通过网络查找仍可访问的比赛。确认赛事、日期和组织信息，避免选中名称相似的其他比赛。
  3. 选择射手与 Stage。核对 division、射手信息、Stage 编号和成绩字段。
  4. 关联对应的本地视频。在自己的比赛视频归档中选择真正记录该射手和 Stage 的素材。
  5. 复核后保存。检查比赛、射手、Stage 与成绩是否一致，再在字幕、归档或后续编辑中使用。

导入需要用户逐项选择和确认。应用不会保证仅凭文件名或相似日期就能把所有视频与成绩自动正确匹配。

用比赛、射手与 Stage 三层信息确认关联

先确认比赛，再确认射手，最后确认 Stage。若一场比赛拍了多个视角或重复录制，应通过画面内容、拍摄顺序和已知 Stage 信息决定哪段视频对应哪条记录。

本地归档价值：已导入的比赛、射手、Stage 与成绩记录可以和自己的本地比赛视频建立关联，后续在整理单段 Stage 或 完整比赛 Merge 时继续复核。

只有特定 PractiScore 记录支持官方逐发锚定

当 PractiScore 成绩本身包含官方 timer 逐发记录时，Shooting Cut 可以用视频中的计时器蜂鸣建立锚点，并在字幕或叠加中使用官方 times、splits、发数和成绩。并非每一条 PractiScore 结果都包含这些字段。

ESS、HDP 与 IDPA 的受支持路径用于成绩导入，不应描述为同类官方逐发时间来源。完整步骤请阅读把官方逐发时间与成绩加入比赛视频。

在来源仍可访问时完成导入

成绩导入依赖外部来源当前仍然提供比赛与结果。如果来源之后撤下、替换或删除记录，Shooting Cut 不能从已不可访问的来源重新取回该结果，也不应承诺恢复来源已删除的数据。

同时参加泰国 HDP 与 ESS 赛事的用户，可阅读泰国 HDP 与 ESS 成绩导入指南，了解两个 portal 的选择方式与 ESS 当前比赛切换风险。

成绩导入会使用网络；媒体编辑仍遵守设备端处理边界。
