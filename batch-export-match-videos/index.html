macOS + Pro · 多个独立文件

在 Mac 批量导出比赛视频

Shooting Cut 的批量导出只在 macOS Pro 中提供：先把多个比赛剪辑分别编辑和复核完成，再把它们作为独立导出任务处理；结果是多个文件，不是由 Merge 连接成的一条长视频。

批量导出处理已经准备好的剪辑

批量导出适合一场比赛结束后，多个 Stage、多个比例版本或多个独立项目都已完成编辑，需要在 Mac 上逐项生成文件的场景。每个任务仍保留自己的素材、模式、字幕、成绩关联、画面比例与导出设置。

这个功能不会把尚未检查的项目自动变成成片，也不代表云端后台替你渲染。核心媒体处理仍在用户的 Apple 设备上完成，批量功能的作用是组织多个独立导出任务。

加入批量导出前先逐个完成复核

  • 确认每个项目使用正确的 Auto Trim、Merge、Split Sync 或 Stage Mix 工作流；
  • 检查蜂鸣声、枪声事件、字幕、成绩和首尾裁剪；
  • 检查 Reframe/Track 的主体、比例和安全区；
  • 为每个任务确认目标文件位置与可用输出选项；
  • 需要长比赛视频时，先在 Merge 内完成顺序组织，而不是期待批量导出自动连接文件。

检测结果需要修正时，请先使用枪声检测排查指南；需要多个发布比例时，请先阅读Reframe 与 Track 输出矩阵。

把独立项目作为多个导出任务处理

  1. 在 Mac 上打开已准备好的比赛剪辑。逐个确认内容、字幕、成绩和构图已达到可导出状态。
  2. 为每个剪辑确认输出设置。使用该模式与源素材允许的比例和分辨率，不复制不适用的设置。
  3. 加入批量导出。把要处理的项目组织为多个独立任务。
  4. 开始处理并关注每个任务。某个任务需要修改时，回到对应项目复核，而不是把错误带入下一次输出。
  5. 逐个检查生成文件。确认文件内容、命名与目标位置，再进入上传或归档流程。

平台边界：当前批量导出仅在 macOS Pro 中提供；iPhone 和 iPad 不提供同一批量能力。

批量处理不会绕过每个模式的输出上限

批量任务仍需遵守的输出边界
工作流可用设置如何决定不支持或不保证
常规横屏或来源比例Original、4K、1080p、720p 会按源素材与处理上限过滤每个源片都一定提供全部选项
Track 裁切裁切后短边 1080 像素，可降为 720p4K Track 输出
Split Sync由四种固定布局控制，短边 1080 像素任意比例与分辨率组合
不同批量任务每个任务使用自己的有效设置一个设置自动适用于所有模式
