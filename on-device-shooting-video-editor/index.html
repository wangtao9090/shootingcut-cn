你的素材如何被处理

Shooting Cut 的核心视频与音频分析、剪辑、导出和人物追踪在用户的 Apple 设备上运行；原始素材不会上传到 Shooting Cut 的媒体处理服务器。用户选择使用的 Apple 或网络功能属于单独例外，包括 iCloud、订阅验证、检测改进、成绩导入和主动发起的平台上传。

“设备端”描述的是核心媒体工作流

计时器蜂鸣声与枪声分析、视频裁剪、顺序合并、双画面同步、多机位剪辑、成绩与计时字幕渲染、画面重构、人物追踪和视频导出，都由用户设备执行。为了完成这些核心操作，Shooting Cut 不会把原始视频、原始音频或提取的 PCM 音频发送到自己的媒体处理服务器。

这不表示应用的每一项功能都不使用网络。素材所在位置、用户的 Apple 设置和主动选择的功能，会决定 Apple 服务或其他网络服务是否参与。

Apple 照片、iCloud 照片与 iCloud 云盘

Apple 照片、iCloud 照片和 iCloud 云盘遵循 Apple 服务与用户设置。若所选素材只存在于 iCloud 照片，Apple 可能按需下载；在 macOS 上选择 iCloud 云盘文件，也可能触发 Apple 管理的上传、下载、缓存或同步。

这些行为由照片权限、Apple ID、iCloud 与设备设置控制，因此不能把云端素材工作流描述为固定离线存储。

iCloud KVS 可以同步的轻量字段

  • 素材别名、机位视角与枪械类型；
  • 视频和成绩之间的关联；
  • 导入的比赛记录，以及对应的比赛与射手字段；
  • 已经存在的非匿名自定义 RevenueCat App User ID。

以 $RCAnonymousID: 开头的 RevenueCat 匿名 ID 不会备份到 KVS。原始媒体文件、PCM 音频、人物追踪路径和关键帧也不会进入 KVS。

订阅身份如何跨设备恢复

如果 KVS 已经保存一个非匿名的自定义 RevenueCat App User ID，应用可在另一台 Apple 设备上读取该 ID，并使用它登录 RevenueCat，从而恢复相应的订阅身份。

RevenueCat 会接收应用或订阅标识符、App Store 交易标识符和订阅权益状态，用于购买验证与跨设备权益同步。RevenueCat 匿名 ID 不进入上述 KVS 备份，RevenueCat 也不接收用户的支付卡详情。

“帮助改进枪声检测”由用户控制

检测改进功能在当前版本中默认开启，但由用户控制。编辑界面的行内开关会显示“改进检测”或简称“改进”，导出设置使用完整标签“帮助改进枪声检测”。

开启时，应用可以向 Apple CloudKit 发送有限的伪匿名派生与纠错字段，例如随机会话和分析标识符、枪声与计时器时间、分析状态、派生频谱或时序特征，以及用户添加、删除、截断或调整检测结果形成的纠错事件。

检测改进报告不包含原始视频、原始音频、PCM 音频、文件内容或人物追踪路径。

关闭、重试与既有报告

  • 关闭期间不会创建新的报告，也不会重试发送本地待处理队列；
  • 关闭不会删除此前已经提交的报告；
  • 关闭不会清空设备上已经存在的本地重试队列；
  • 再次开启后，应用可能继续重试该队列。

成绩导入与平台上传由用户发起

成绩导入使用网络。只有当用户选择导入时，应用才会向相应成绩来源请求比赛、赛段、射手、成绩与可用计时记录。

YouTube 和 Facebook 上传同样由用户主动发起。只有在选择平台、完成授权并确认后，应用才会把所选导出视频、访问令牌以及完成上传所需的账号或视频元数据发送给该平台。OAuth 令牌保存在系统钥匙串中，应用不会取得用户的平台密码。

联网服务、云服务和本地设备都存在各自风险边界；更完整的控制、保留和安全说明请查阅隐私政策。

常见问题

原始视频会上传到 Shooting Cut 的媒体处理服务器吗？

不会为了完成核心分析、剪辑、导出或人物追踪而上传。原始素材保留在用户选择的设备、照片图库或 Apple 存储位置；用户主动选择 YouTube 或 Facebook 上传时，所选导出文件会发送给相应平台。

设备端处理是否表示所有功能都离线？

不是。Apple 照片与 iCloud 云盘会按用户设置使用 Apple 服务；订阅验证、可选检测改进、成绩导入，以及用户主动发起的平台上传也会使用网络。

iCloud KVS 会同步哪些内容？

KVS 可同步素材别名、机位视角、枪械类型、成绩关联、导入的比赛与射手字段，以及已经存在的非匿名自定义 RevenueCat App User ID。原始媒体、PCM 音频和人物追踪路径不会进入 KVS。

怎样关闭检测改进数据发送？

关闭编辑界面中的“改进”或“改进检测”，也可以在导出设置中关闭“帮助改进枪声检测”。关闭期间不会创建新报告，也不会重试本地待处理队列；此前已提交的报告不会因此删除，本地队列也不会被清空。
