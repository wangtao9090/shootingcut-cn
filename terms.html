4. 应用功能与特性

当前版本为 1.1.3。ShootingCut 提供以下核心功能：

  • 音频分析：从导入视频的音轨中检测电子计时器蜂鸣声与枪声事件，供剪辑和计时字幕使用。
  • 自动裁剪（Auto Trim）：每次处理正好 1 个视频，根据检测结果和用户设置裁去赛段前后的空白部分。
  • 视频合并（Merge）：按顺序合并最多 20 段视频。
  • 分屏同步（Split Sync）：同步正好 2 个同时拍摄的视角，并以支持的双画面布局导出。
  • 场景混编（Stage Mix）：接收 2–3 个标记为 POV、Follow 或 Static 的输入，根据移动状态自动切换机位，并允许手动调整。
  • 字幕叠加：将实时成绩统计数据（各枪时间、Split 间隔、总用时等）以字幕形式叠加于导出视频中。
  • 人物追踪与画面重构：使用 Apple Vision 在设备端追踪所选人物，并为不同导出比例计算画面裁切。
  • 成绩导入：通过网络从受支持的 PractiScore、ESS、HDP、IDPA 等来源导入比赛、成绩或官方计时记录。
  • iCloud 元数据同步：素材别名、视角、枪械类型、成绩关联、导入比赛记录，以及已经存在的非匿名自定义 RevenueCat App User ID 等轻量数据可通过用户自己的 iCloud KVS 跨设备同步；以 $RCAnonymousID: 开头的 RevenueCat ID、原始媒体、PCM 音频和人物追踪路径不使用该机制同步。
  • 平台上传：用户可主动把所选导出视频上传到 YouTube 或 Facebook（需单独授权）。当前版本不提供 TikTok 视频直传。

各平台（iOS、iPadOS、macOS）的界面和部分功能可能有所差异，功能也可能随版本更新而变更。需要付费权益的功能通过订阅提供。
