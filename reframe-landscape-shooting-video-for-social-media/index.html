从横屏素材到多个版本的五个步骤

  1. 完成基础编辑。先处理单段裁剪、多段合并或多机位切换，确认需要重构的最终内容范围。
  2. 选择 Track 并指定主体。Shooting Cut 在设备端分析画面中的目标人物，为裁切窗口提供运动路径。
  3. 选择适用比例。Track 比例为 9:16、3:4、4:5、6:7 和 1:1；Source 与非追踪的 16:9 属于另外的输出路径。
  4. 预览主体位置。检查快速移动、遮挡、边缘构图和切换点，必要时重新追踪或改用手动裁切。
  5. 按用途重复导出。保留同一份素材与追踪结果，依次生成需要的比例，而不必重新拍摄。

Track 是辅助构图工具，不会替代最终预览。尤其在移动快、画面被遮挡或主体靠近边缘时，应从头到尾检查裁切窗口。

Reframe 在三种模式中支持 Track

不同编辑模式的 Reframe 路径
模式Track手动裁切关键边界
Auto Trim支持支持每次处理恰好一段 Stage 视频
Merge支持支持最多 20 段顺序素材
Stage Mix支持以当前工作流提供的重构方式为准2–3 个 POV、Follow 或 Static 输入
Split Sync不走常规 Track 比例流程由布局定义画布恰好两个同步输入，输出由所选布局控制

Auto Trim 与 Merge 即使不使用 Track，也可以手动裁切。Split Sync 的四种布局负责组合两个同步画面，因此不能把它理解为任意 Track 比例与任意分辨率的自由组合器。

不要把选项做笛卡尔积。Original、4K、1080p 和 720p 是常规输出选择，并不表示每一种比例都能搭配每一种分辨率；源素材和具体处理流程会过滤可用选项。

用运动过程检查裁切，而不只看第一帧

竞技射击中的启动、横移、进出射击位置和快速转向会改变主体在画面中的位置。预览时应关注头部与脚部是否被切断、枪械方向是否留有空间、遮挡后追踪是否恢复，以及从一个位置移动到下一个位置时画面是否过度晃动。

  • 主体选择不正确时，重新指定目标并追踪；
  • 自动路径不适合某个片段时，回到预览修正或使用手动裁切；
  • 比例越窄，越要检查横向移动和边缘空间；
  • 导出前同时检查字幕、安全边距与裁切窗口。

这些分析与编辑在设备端完成。有关本地处理、可选改进数据和外部分享边界，请阅读设备端视频编辑说明。

保留一个项目，按发布用途逐次导出

建议先确定一份内容完整、字幕正确的主编辑结果，再按用途导出 9:16、4:5、1:1 或横屏版本。平台名称在这里仅用于解释常见画面用途，不代表自动发布能力，也不改变上述输出边界。
