Merge 连接不同时间发生的 Stage

Merge 面向顺序关系：Stage 1 完成后才是 Stage 2，再到 Stage 3，依次形成整场比赛。一次 Merge 最多加入 20 段视频，你可以按照真实比赛顺序重排，也可以暂时排除不准备出现在成片中的片段。

每段输入仍是独立的 Stage 素材。若原片已经关联对应成绩，Merge 会保留各输入自己的成绩关联，而不是把某一段的成绩套到整条合并视频上。

先处理单段，再组织整场。需要缩短某个 Stage 的首尾空白时，可先使用 Auto Trim 完成单段裁剪与复核，再进入 Merge 排序。

制作完整比赛视频的五个步骤

  1. 准备 Stage 素材。确认每段视频对应哪一个 Stage，并先完成必要的单段裁剪、字幕和成绩关联。
  2. 加入 Merge。选择要纳入整场视频的片段，一次最多加入 20 段。
  3. 按 Stage 顺序排列。把素材整理为 Stage 1、Stage 2，直到 Stage N；若比赛实际顺序不同，以真实拍摄和参赛顺序为准。
  4. 逐段纳入或排除并复核。检查每一段的内容、首尾衔接、成绩关联和是否应出现在本次成片中。
  5. 预览并导出。从开头连续检查到结尾，再生成完整比赛视频或个人归档文件。

Merge 不会替你生成自动章节。若发布平台需要章节，可在导出后根据 Stage 顺序手动整理时间点和说明。

逐段复核比只看最终长度更重要

合并前的逐段检查
检查项要确认的内容常见处理
顺序Stage 编号与实际比赛先后是否一致拖动重排，避免漏段或重复
纳入状态练习片段、误录或不准备发布的片段是否被加入逐段选择纳入或排除
首尾每段是否留有过长等待，最后动作是否被截断返回单段编辑调整裁剪
成绩关联每个输入是否关联自己的 Stage 成绩在对应输入上修正，不跨段替换
构图不同输入的方向和画面比例是否符合成片目标需要时先使用手动裁切或 Reframe

如果同一段横屏素材还要输出竖屏或方形版本，可参阅 Reframe 与 Track 指南。Merge 支持手动裁切；Track 则适合需要持续跟随主体的比例重构。

标题应让观众知道比赛范围

完整比赛视频可以在标题中写明赛事、日期、分组或器材，并用“完整比赛”“全部 Stage”“POV”或明确的 Stage 数量告诉观众内容范围。例如：“USPSA 月赛完整比赛｜8 个 Stage｜POV”。不要把实际缺少的 Stage 描述为“全部”。

长视频适合由用户主动上传到 YouTube，也适合作为个人比赛归档。Shooting Cut 还支持由用户主动发起的 Facebook 上传；你也可以先导出文件，再使用自己的发布或存档流程。

Merge 与 Split Sync、Stage Mix 不是同一种关系

先后

Merge

连接不同时间发生的多个 Stage，最多 20 段，目标是整场比赛或顺序归档。

同步

Split Sync / Stage Mix

处理同一次 Stage 的同步机位：Split Sync 恰好两个输入，Stage Mix 使用 2–3 个角色化输入。

macOS Pro 的批量导出用于批量处理多个导出任务，不等同于 Merge。Merge 的核心仍是把选定片段按顺序组成一条视频。
