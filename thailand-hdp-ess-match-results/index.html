HDP 与 ESS 的参赛人群明显重叠，但 portal 行为不同

泰国有不少射手同时参加 HDP 与 ESS 赛事，因此同一个本地视频归档可能需要两套成绩导入路径。这里不使用某一场比赛的内部姓名样本，也不发布不稳定的精确重叠比例；实际选择应以你参加的赛事和来源当前页面为准。

ESS 的关键风险是当前比赛切换。portal 通常把公开入口指向当前比赛；当新的已发布比赛替换它时，旧比赛或成绩页面可能不可访问。不要等到整理视频时才第一次尝试导入。

立即动作：只要 ESS 成绩仍可访问，就先导入比赛、division、射手与成绩，再与对应本地视频关联。Shooting Cut 能保留已经导入的记录，但不能在 ESS 来源删除后恢复原本没有导入的结果。

HDP：从已结束比赛或 scoreboard 选择

  1. 进入 HDP 成绩导入。选择与比赛状态相符的已结束比赛或 scoreboard 入口。
  2. 核对比赛。使用赛事名称、日期与组织信息确认不是名称相近的其他场次。
  3. 选择射手和 Stage。逐项核对成绩与自己的比赛视频内容。
  4. 导入并关联。把选定记录关联到对应的本地 Stage 视频。

这里描述用户能看到的选择方式，不依赖内部样本姓名，也不公开可能变化的实现 URL。

ESS：选择比赛、division 与射手

  1. 在当前可访问的 ESS 比赛中开始。先确认赛事与日期。
  2. 选择 division。缩小到自己实际参赛的组别。
  3. 选择射手。核对射手身份与成绩，不用名称相似度代替人工确认。
  4. 立即导入。在 portal 切换到下一场当前比赛前保存可用记录。

如果旧 ESS 比赛已经无法从来源访问，Shooting Cut 不能从该来源恢复未曾导入的结果。对已经导入的记录，应继续与自己的本地比赛视频归档一起管理和复核。

HDP 与 ESS 成绩不提供 PractiScore 风格逐发锚点

HDP 与 ESS 的受支持路径用于比赛与成绩导入，不提供 PractiScore 风格的官方 timer 逐发时间。不要把来源成绩与应用从视频音频中辅助检测的枪声事件混为同一类官方记录。

只有 PractiScore 成绩本身含官方逐发 timer 记录时，才能按对应工作流把官方 times、splits、发数与成绩锚定到视频。详见时间与成绩字幕指南。
