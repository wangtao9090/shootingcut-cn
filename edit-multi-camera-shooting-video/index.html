同一次 Stage · 2–3 个角色化机位

剪辑多机位射击视频

要把同一次 Stage 的多个同步视角剪成一条有节奏的成片，可在 Shooting Cut Pro 中使用 Stage Mix：导入 2–3 个视频，分别标记为 POV、Follow 或 Static，让移动状态驱动自动切换建议，再逐个切点手动复核或覆盖。

Stage Mix 只处理 2–3 个同步输入

Stage Mix 的素材必须来自同一次 Stage，输入数量为2–3 个。它不支持无限机位，也不应描述为四个或更多输入的工作流。每段素材需要分配一个角色：POV、Follow 或 Static。

角色告诉自动切换逻辑每个画面的观看价值，但不会替用户决定最终成片。素材之间仍需具有可比较的同步事件，并在自动结果生成后完成手动复核。

先确认素材关系。如果只有恰好两个画面并希望固定组合展示，使用 Split Sync；如果是 Stage 1 到 Stage N 的顺序片段，使用 Merge。

POV、Follow 与 Static 各自提供什么信息

Stage Mix 输入角色
角色典型画面复核重点
POV从射手视角记录瞄准方向、进出位置和操作节奏快速转向时画面是否仍可读，是否需要在移动段切离
Follow由跟拍者持续观察射手移动与射击动作遮挡、跟随稳定性与安全边距
Static从固定位置展示场景、路线与整体移动主体离开覆盖范围时是否应切换到其他角色

同一种角色不代表所有素材都必须以相同方式使用。选择角色后仍要结合这个 Stage 的路线、遮挡和画面质量判断切换。

从角色标记到多机位成片的五个步骤

  1. 导入 2–3 个同步视频。确认它们记录同一次 Stage，并保留可用于对齐的蜂鸣声与动作。
  2. 为每个输入分配角色。只使用 POV、Follow 或 Static，按实际拍摄方式选择。
  3. 生成自动切换建议。Stage Mix 根据射击与移动状态提出机位切换，让成片先形成可审阅的结构。
  4. 手动复核与覆盖。逐个检查切点，替换不合适的机位，修正过早、过晚或遮挡中的切换。
  5. 完整预览并导出。检查同步、切换节奏、字幕、构图和首尾边界，再输出最终视频。

自动切换是起点，不是不可编辑的结论。用户可以保留合适的建议，也可以用手动覆盖决定任何需要调整的切点。

用射击段与移动段复核切换节奏

先按 Stage 的实际过程检查：蜂鸣声之后的启动、进入第一个位置、射击、换位、再次射击，直到结束。自动切换可能因为遮挡、相机晃动、较弱蜂鸣声、邻近枪声或回音而需要调整。

  • 射击动作发生时，当前机位是否能清楚表达关键过程；
  • 移动段是否提供足够场景信息，而不是频繁切换造成混乱；
  • 切点前后是否同步，没有让动作突然跳跃；
  • 某个输入画面失去主体时，是否及时切到更合适的角色；
  • 最终字幕和重构后的安全区域是否完整。

若蜂鸣声或枪声事件本身不准确，先按照检测排查步骤修正，再判断切换节奏。

Stage Mix
